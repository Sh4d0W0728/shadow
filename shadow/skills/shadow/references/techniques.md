# 常用剪辑技巧：按意图选用

只查当前配方引用的 ID；不要把本表全部堆进一个视频。每个数值都是**第一次预览的起点**，会随内容、素材、音乐和观众改变；不是行业标准或验收要求。用户给出的时长、平台、镜头、配乐、字幕、留白和禁用效果始终优先。

实现状态：`基础`＝v1/v2 均可表达镜头顺序、源入出点及硬切。`v2`＝使用 `schema_version: 2` 的新增能力，具体字段、限制和 XML 交接方式以 [timeline-v2.md](timeline-v2.md) 为准，不能沿用 v1 的能力上限。`原生`＝Premiere 原生编辑流程；除同项明确标注的 v2 能力外，脚本没有自动实现。`策划`＝提供选镜与时间点，是否成立需要看素材和试听。`预处理`＝只有对应脚本、依赖与测试确认后才能宣称已应用；当前不要从名称推断功能已实现。v2 图片文字不是可直接编辑字词的 PR 原生文字，XML 生成也不等于 Premiere 已验收。引用 ID 的配方见 [workflows.md](workflows.md) 和 [recipes.json](../assets/recipes.json)。

## S — 让观众看懂故事、观点和任务

| ID / 技巧 | 意图与适用条件 | 避免或调整的条件 | 实际起点 | 实现状态 |
|---|---|---|---|---|
| S01 先组故事骨架 | 用关键事实、动作或歌词段落搭起能独立理解的主线；访谈、教程、叙事 MV | 不用配乐强行掩盖逻辑缺口；不能创造素材没有的因果 | 先选 3–7 个必要节点，每节点写一句功能 | 策划＋基础 |
| S02 首屏承诺 / 问题钩子 | 产品、教程、社交短片迅速交代值得继续看的结果 | 用户要求慢开场、仪式完整记录、无悬念风格时尊重它 | 短片首 1–3 秒呈现一个清楚问题、结果或动作 | 策划＋基础；文字可用 v2 PNG 或 PR 原生 |
| S03 冷开场 | 用片中强时刻先建立兴趣，再进入背景 | 不让摘出的句子失去原意；提前揭底会损害悬念时不用 | 2–8 秒有独立吸引力的片段，再接建立镜头 | 策划＋基础 |
| S04 纸面剪辑 / 反向提纲 | 先按转录挑句子，或给现有片段标功能；口播、纪实 | 没有核验转录时不能替换原声；不要只按关键词拼句 | 每段保留“主张—证据—意义”，先去重复再润色 | 策划＋基础 |
| S05 铺垫—递进—兑现 | 产品、故事、挑战类内容形成可感知的变化 | 不为了三段式改写真实事件；纯教学可用步骤结构 | 先试约 20% 铺垫、60% 递进、20% 兑现，再按素材调 | 策划＋基础 |
| S06 动作—反应 | 用人物反应解释动作的情绪和结果；人物混剪、活动 | 无关反应不能被伪装成同一事件的真实回应 | 动作结束前后寻找 0.5–3 秒有意义的反应 | 策划＋基础 |
| S07 平行剪辑 | 交替两条相关行动建立比较或紧张感 | 无证据时不要让观众误以为两件事同时发生 | 先 A–B 各 2–3 次，保持地点和人物可辨 | 策划＋基础 |
| S08 延后揭示 / 信息分配 | 先给线索后给答案，适合有真实揭示时刻的故事 | 不隐藏理解下一步所必需的信息；不造假悬念 | 揭示前保留 1–2 条看得懂的线索 | 策划＋基础 |
| S09 省略重复过程 | 加快等待、重复劳动、旅行路程；教程、产品、Vlog | 安全步骤、关键证据、不可逆操作不能跳过 | 保留开始、一个中间状态和结果，重复部分缩至 10–30% | 策划＋基础 |
| S10 章节地标 | 长教程、旅行或纪实帮助观众知道进度和地点 | 连续情绪段中标题过多会打断体验 | 按真实阶段设章；约 2–5 秒章标题只是起点 | 策划＋基础；文字可用 v2 PNG 或 PR 原生 |

## C — 让镜头接得清楚、自然

| ID / 技巧 | 意图与适用条件 | 避免或调整的条件 | 实际起点 | 实现状态 |
|---|---|---|---|---|
| C01 有动机的硬切 | 时间、地点、动作或信息发生变化时切；通用基础 | 无新信息的频繁切换会消耗注意力 | 先用硬切建立全部结构，只在必要位置加转场 | 基础 |
| C02 动作接剪 | 在同一动作上切到另一角度，减少接缝感 | 动作相位、方向不一致会产生倒退或跳跃 | 在动作中段试切，前后移动 1–4 帧看连贯性 | 策划＋基础 |
| C03 形状 / 动作匹配剪辑 | 用构图、运动或概念呼应连接不同场景；MV、广告 | 找不到真实相似性时勿硬套；不要掩盖事实关系 | 先选明显共同元素，试 0–4 帧间隔的硬切 | 策划＋基础 |
| C04 视线与主体位置衔接 | 对话、人物行动让观众知道在看谁、看哪里 | 跨轴会改变左右关系；有意迷失需有叙事动机 | 比较前后视线和主体位置；必要时加中性过渡镜头 | 策划＋基础 |
| C05 全景—中景—细节 | 先交代环境，再看行动和细节；旅行、活动、产品 | 风格要求直接细节开场时可倒序，但及时补环境 | 一个场景先试 2–5 个景别，不为凑数重复镜头 | 策划＋基础 |
| C06 插入镜头 / Cutaway | 展示说话内容的物件、观众、手部或环境，覆盖合理接缝 | 无关镜头会让观众误解；不能遮盖缺失的关键证据 | 1–4 秒相关镜头，覆盖剪点并保留上下文 | 基础；保留原声需人工轨道编辑 |
| C07 有意跳切 | 删除口播赘语、做喜剧或表现时间流逝 | 不能把不同句子拼成相反意思；抒情慢段慎用 | 先只去重复或空转，留下自然的句首句尾呼吸 | 基础；原声拼接需核验 |
| C08 运动方向一致 | 同一段行动保持入画、出画和镜头运动方向 | 回头、转弯等真实方向变化应保留解释 | 检查相邻 2–3 镜头的方向；必要时用正面或全景重置 | 策划＋基础 |

## R — 控制节奏、音乐和情绪

| ID / 技巧 | 意图与适用条件 | 避免或调整的条件 | 实际起点 | 实现状态 |
|---|---|---|---|---|
| R01 乐句切点 | 跟随小节、乐句或歌词意义结束；抒情 MV、旅行 | 不因鼓点打断未完成动作或一句话 | 先在 2/4/8 小节边界找段落，再确定镜头内切点 | 策划＋基础 |
| R02 重拍同步 | 冲击性混剪、动作、产品揭示让视觉重点落在强拍 | 不把每拍都变成剪点；检测到的拍点须试听 | 先每 2–4 拍切一次；峰值可短暂加密到每拍 | 策划＋基础；自动拍点未确认 |
| R03 反拍 / 切分 | 少量偏离强拍创造呼吸和惊喜 | 全片偏移会显得失误；口型和对白不能随意错位 | 每 4–8 次同步切中选 1 次稍提前或延后 | 策划＋基础 |
| R04 节奏递进 | 通过镜头变短、动作变强、信息变密逐步升温 | 高密度不等于情绪强；不能牺牲理解和安全操作 | 示例由 3–5 秒逐步缩到 1–2 秒，再留一个释放镜头 | 策划＋基础 |
| R05 长镜停留 / 释放 | 在情绪、关键表情、完成动作或证据上停留 | 不把静止空镜机械拉长；对白需要的时长优先 | 普通段 2–4 秒，情绪落点可先试 4–8 秒 | 策划＋基础 |
| R06 恒速慢动作 | 运动、美感、情绪强调；有足够采样帧的源素材 | 低帧率会卡顿；口型与对白通常不宜减速 | 无补帧的参考倍率为序列帧率/拍摄帧率，如 25/50=50% | Premiere 原生；基础脚本不自动变速 |
| R07 速度渐变 / Speed ramp | 有明确动作峰值的运动、转场或产品镜头 | 模糊、遮挡和细线易出现补帧伪影；对话慎用 | 动作峰值附近从正常转慢，过渡先试 6–12 帧 | 原生 Time Remapping；基础 XML 不承诺 |
| R08 视觉母题重复 | 同一物件、动作或构图承载情绪变化；MV、人物 | 同一镜头反复放可能只是素材不足；每次须有功能 | 2–4 次出现，最后一次改变语境或结局 | 策划＋基础 |
| R09 同屏比较 / 分屏 | 教程前后对比、产品规格、平行动作 | 竖屏空间不足、字幕拥挤或主体过小则改单镜比较 | 先试双画面，并列停留 3–6 秒让差异看得清 | 原生；基础脚本不生成分屏 |

## A — 声音组织与过渡

| ID / 技巧 | 意图与适用条件 | 避免或调整的条件 | 实际起点 | 实现状态 |
|---|---|---|---|---|
| A01 先剪对白主线 | 访谈、讲解、纪录内容先确保信息与原意完整 | 不用删口头语作为唯一质量标准；保留有表达作用的犹豫 | 按完整意思组段，再去重复；短停顿先试听而非一律删 | 策划＋基础；音频联动需核验 |
| A02 J cut | 下一场声音先进入，再换画面；引入人物或空间 | 下一场声源不明或会造成事实误解时不用 | 音频提前 0.2–1.5 秒，再按语句和现场声调整 | Premiere 原生分离剪辑；基础脚本不生成 |
| A03 L cut | 上一场声音跨到下一镜；反应、B-roll、访谈 | 不让上一人的话看似出自下一人；空间突变需解释 | 原声延后 0.3–2 秒或到自然句尾 | Premiere 原生分离剪辑；基础脚本不生成 |
| A04 Room tone / 环境底 | 修补同一场景的静音接缝，保持空间连续 | 不把其它地点声景伪装成同期证据；不要复制明显重复音 | 选 2–10 秒干净同场环境底，短淡化接合 | 原生音轨编辑 |
| A05 对白优先压音乐 | 口播、教程、访谈让语言可懂 | 无对白的 MV 不应套口播压音量；不能只看仪表 | 音乐先试低于对白感知响度约 10–18 dB，逐句试听调整 | 原生关键帧 / Ducking；基础脚本不自动侧链 |
| A06 声音桥 | 用同一声响跨场景建立联系；纪录、MV、旅行 | 真实纪录须分清设计声与同期声；勿制造虚假证据 | 声音跨切点约 0.5–2 秒，长度由声响本身决定 | 原生音轨编辑 |
| A07 少量音效标点 | 强调一个动作、揭示或界面操作；产品、短片 | 每次切镜加 whoosh 会疲劳；音效不能盖住对白 | 每个重要段落选 1–3 个明确动作点，先低音量试听 | 原生；需实际有授权音效 |
| A08 音频交叉淡化 | 消除接缝爆音或同场音底突变 | 同时出现两句对白会难懂；音乐节拍相位须试听 | 接缝先试 2–6 帧，跨环境可试 0.1–0.5 秒 | v2 支持相邻画面转场重叠区的 audio: crossfade，XML 按能力原生映射或局部烘焙；任意 J/L cut、独立音频包络仍需原生编辑与试听 |
| A09 响度与峰值整理 | 输出音量稳定、避免削波；多素材拼接 | 不用提高响度补救噪声；平台目标需按实际规范 | 未给目标时先做一致性试听并留峰值余量；不要自动套统一 LUFS | 原生；预处理仅在命令与结果实测后宣称 |

J/L cut 的音画先后定义与 Premiere 分离编辑操作以 [Adobe 官方说明](https://helpx.adobe.com/in/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html) 为依据；上表的时间范围是本库的试剪建议。

## V — 画面、色彩与转场

| ID / 技巧 | 意图与适用条件 | 避免或调整的条件 | 实际起点 | 实现状态 |
|---|---|---|---|---|
| V01 先匹配曝光和白平衡 | 多机位、混合光源避免切换跳色 | 不把不同时间地点都修成相同光线；肤色和意图优先 | 先选一张正常肤色/中性物作参照，逐镜匹配再加风格 | Premiere 原生色彩工具 |
| V02 统一风格调色 | 结构完成后赋予稳定冷暖、反差和饱和度 | LUT 不能替代曝光修正；未知 Log/色彩空间不乱套 | 从温和强度开始，逐镜检查肤色、暗部和高光 | 原生；基础脚本不自动调色 |
| V03 选择性防抖 | 轻微非意图手持抖动影响观看时 | 大幅摇移、运动模糊、滚动快门或有意手持不宜强稳 | 先低强度试一段，检查裁切、边缘拉伸和稳定器漂移 | 原生；基础脚本不运行防抖 |
| V04 构图重整 | 构图偏差、横竖版适配、产品重点 | 放大会降低有效清晰度；勿裁断演示关键区域 | 源分辨率允许时先试 105–120% 的温和放大 | 原生；预处理静态适配须确认参数 |
| V05 有动机的叠化 | 表示时间流逝、回忆、轻柔场景过渡 | 不能用叠化遮盖所有错误；运动重影影响阅读 | 先试 6–20 帧，并确认两端有素材余量 | v2 dissolve 可渲染；XML 按 auto/native/bake 及实际媒体交接，原生效果仍需 PR 核验 |
| V06 黑场 / 淡黑 | 明确段落结束、时间变化、沉重停顿 | 用户要无缝节奏或信息连续时少用；黑场不等于渲染漏帧 | 淡化 8–20 帧，黑场先试 0.2–1 秒 | v2 fadeblack 在重叠区中点过黑，XML 用局部烘焙；另需停黑时用明确静态黑图或原生编辑并在计划标记 |
| V07 借运动的转场 | 用真实遮挡、甩镜、进出画等衔接镜头 | 没有匹配素材时不硬套插件；频繁使用会抢内容 | 先找方向一致的运动两端，硬切看是否已成立 | 策划＋基础；附加模糊/遮罩原生 |
| V08 温和 Punch-in | 口播强调观点、覆盖跳切、教程放大细节 | 低分辨率或主体会出框时不用；不每句都缩放 | 先试 108–115% 放大，重要段落才变化 | 原生；基础脚本不生成关键帧 |
| V09 定格 / 停顿强调 | 喜剧、运动解析、人物介绍停在清晰帧 | 定格帧模糊、表情失当，或需真实连续证据时慎用 | 先试 0.5–2 秒，配解释或明确的节奏动机 | 原生；基础脚本不生成 |
| V10 有信息的 B-roll | 用过程、细节、现场画面补充主线；口播、纪录、产品 | 不用无关库存镜头代替真实证据；不能只为填满时间 | 每个解释点选 1–3 镜头；镜头长度由能否看清决定 | 基础；对白保留与叠层原生 |

恒速与速度渐变是不同实现。Premiere 的速度调整方式见 [Adobe 速度与持续时间说明](https://helpx.adobe.com/ca/premiere/desktop/edit-projects/change-clip-speed/different-ways-to-change-clip-speed-and-duration.html)；渐变关键帧见 [Time Remapping 官方操作](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-speed/change-clip-speed-and-duration-using-time-remapping.html)。本插件不能仅靠写入剪辑计划就宣称效果已执行。

## T — 文字帮助理解，不挤占画面

| ID / 技巧 | 意图与适用条件 | 避免或调整的条件 | 实际起点 | 实现状态 |
|---|---|---|---|---|
| T01 可读字幕 | 对话、讲解、无声观看时确保内容可读 | 已有烧录字幕要避免重复；保留用户字幕样式 | 1080 高度先试 36–56 px 等效字号、1–2 行；实际在目标尺寸看 | v2 读取定时 SRT/ASS 生成 PNG 字幕及独立 SRT，不复现复杂 ASS；可编辑 PR 字幕需导入 SRT 并处理重复 PNG 层 |
| T02 语义组句与同步 | 按完整短语断行，避免字幕过快或滞后 | 人名、数字、否定词不能省错；机器转录要听校 | 一般短句先试 1.2–3 秒；语速、字数和停顿优先 | 策划＋原生；需真实转录/时间点 |
| T03 文字层级 | 名称、卖点、证据、注释分主次；产品、教程 | 一屏多个同等大标题会竞争注意力 | 一屏一个主信息，辅助信息约主字号的 55–75% | v2 titles 生成 PNG 图层，改字需重生；可直接编辑字词的 PR 标题仍需原生文字 |
| T04 步骤标注与指示 | 教程让观众知道看哪里、做什么 | 指示不得盖住目标按钮、参数或危险提示 | 每步一个动词＋对象；框选/箭头约停 2–5 秒 | 原生；基础脚本不创建图形 |
| T05 歌词作为节奏线索 | 逐句歌词引导意象、情绪和出现时间；歌词 MV | 不把所有歌词画面化成字面拼贴；用户未要求字幕可只作策划依据 | 按一句/半句分段，关键词选镜，句末允许呼吸 | 策划＋原生；歌词身份及时间需核验 |
| T06 有目的的结尾卡 | 产品、活动、教学需要明确下一步 | 无推广意图的 MV、纪录不用硬塞 CTA；不编造链接 | 结尾 2–5 秒呈现一个实际可执行动作 | v2 可组合静态图片与 PNG 文字卡；PR 原生可编辑文字另做 |

## 节省决策时间的用法

从 [配方](../assets/recipes.json) 选最贴合主导目标的一个，只采用其核心技巧，再增加至多几个确有用途的可选技巧。混合类型以真实主线为主，例如“产品介绍＋采访”先确保采访原意，再加产品 B-roll；“歌词＋卡点”先确认歌词段落和歌曲结构，再在副歌增加重拍切点。预览未证明某个技巧有用时，删掉它比增加参数更快。
