## 蒙太奇 → MS01、MS02

来源：[靠剪接就能颠覆电影行业？蒙太奇到底有啥魔力](https://www.youtube.com/watch?v=sBpKStrL-pY)，2023-04-14。访问：中文转录 00:05–08:23；无对白电影示例未逐帧核验。定位：00:57–01:29 镜头组合；01:31–02:09 时间伸缩；05:43–06:17 连续/交叉；07:09–07:54 隐喻/重复。

来源事实：并置会改变镜头意义；剪接能改变时间感，重复意象可强化主题。

**MS01 镜头意义与因果**｜S01、S06、S07。触发：跨场景或动作—反应组接。动作：每刀写明新增信息及其暗示的关系。验收：主线清楚、关系有依据。避用：纪实素材不得暗示虚假因果或同时发生。状态：策划＋基础组接，需审看。

**MS02 时间压缩与母题**｜S09、R08。触发：重复过程或主题呼应。动作：保留开始、变化、结果；意象再现时改变语境。验收：省略后仍可理解，每次重复有作用。避用：关键操作、证据不能略去。状态：策划＋基础组接。

## 预告片 → MS03、MS04

来源：[用2分钟把你“骗”进电影院？预告片到底怎么剪](https://www.youtube.com/watch?v=6VswjsGwm5o)，2023-03-06。访问：中文转录 00:00–13:18；音乐与插片未完整试听/审看。含大波浪公司刘婧、李小融访谈，不能把全部观点归于 Tim。定位：03:04–03:22 观众笔记；05:09–05:38 停顿；06:21–06:59 宣传阶段；11:38–12:29 长短对照。

来源事实：以观众体验寻找情绪入口；宣传任务影响信息选择，重点停顿与快慢变化能形成对照。

**MS03 受众任务与情绪标记**｜S02、S04、S05。触发：宣传片、预告、活动短片。动作：先写观众、传播任务、核心信息，再标记素材中的情绪时刻。验收：片段服务任务且保留原意。避用：教学片不机械套悬念。状态：策划，需实际选片。

**MS04 密度变化与停顿**｜R04、R05。触发：全片节奏平直或重点被淹没。动作：试递进段与落点停留两种剪法。验收：重点看得懂、情绪可释放。避用：不为提速截断句意或必要动作。状态：基础时长可表达，效果待成片审看。

## 压缩器 → MS05、MS06

来源：[【干货】让声音更清晰的利器：压缩器！达芬奇音频教程第三集！](https://www.youtube.com/watch?v=wZgRi3a9qMQ)，2021-07-13，主讲王也。访问：中文转录 00:00–09:12；未试听 A/B 示例。定位：00:14–01:20 增益/动态；01:45–03:07 阈值/比例；03:59–07:10 启动/释放；07:13–08:55 补偿、闪避与情绪。

来源事实：只增益可能放大峰值；压缩时间参数影响自然度，人声可驱动音乐闪避，仍应保留情绪起伏。

**MS05 动态与压缩**｜A01、A09。触发：对白忽大忽小。动作：先测听，再调阈值、比例、启动与释放，最后补偿。验收：峰值受控且音头、情绪保留。避用：不拿压缩补救失真或套统一 LUFS。状态：Premiere 原生处理；本课为 Fairlight，控件需另核验。

**MS06 音乐闪避与试听**｜A05、A08、A09。触发：音乐遮对白。动作：按语句做音量包络，比较处理前后。验收：逐句可懂、无突兀抽吸。避用：纯音乐 MV 不套对白模板。状态：原生关键帧/闪避，脚本未自动实现；静音学习不能算试听通过。

## 素材管理 → MS07、MS08

来源：[关键素材被删！找不到素材？影视飓风是如何摆脱丢数据噩梦的](https://www.youtube.com/watch?v=RTqNZEFp0o4)，2022-05-06。访问：中文转录 00:00–11:22；目录示意图未逐项读取。定位：00:55–02:29 目录/命名；03:28–05:28 拷卡/校验；05:35–06:34 备份；09:07–09:39 归档；10:14–10:41 母带。

来源事实：固定目录规则、保留源素材名，完整拷卡后校验；分散备份风险，归档时兼顾后续使用。

**MS07 源包、工作副本与命名**｜D01。触发：接收原片。动作：保留源名与卡目录，分类编号只写工作副本并保存映射。验收：能追溯来源、原片未改。避用：视频分类目录不能当整卡备份。状态：[整理脚本](organize.md) 已支持副本/映射；整卡归档另做。

**MS08 校验、归档与母版**｜D01、A09。触发：复制或交付。动作：核验摘要和解码，记录真实备份位置；另存工程与所需母版。验收：副本完整、新工程可打开、规格正确。避用：不自动清卡/删原片；MD5 本属 hash，不照搬泛化速度比较。状态：SHA-256 已实现；解码、备份恢复及母版须实际执行核验。

## Adobe 操作补充：独立于课程来源

以下官方正文于核验日读取，页面更新 2026-01-07。用于将建议落到 Premiere；并不证明插件已代替用户操作软件。

- [复制项目](https://helpx.adobe.com/premiere/desktop/organize-media/create-projects/copy-project.html)：`File > Project Manager` → 选序列 → `Collect Files and Copy to New Location`。按需求选择是否排除未用素材；收集后打开新工程检查。复制媒体改名选项通常保持关闭，以映射保存描述。
- [创建代理](https://helpx.adobe.com/premiere/desktop/organize-media/ingest-proxy-workflow/create-proxies.html)：项目面板选在线视频 → `Proxy > Create Proxies`，指定预设和独立代理目录，由 Media Encoder 生成。代理不是原片备份。
- [导出代理](https://helpx.adobe.com/premiere/desktop/organize-media/ingest-proxy-workflow/export-proxies.html)：默认导出使用全分辨率媒体；只有明确选择 `Use Proxies` 才使用代理，交付时检查选择和输出规格。
