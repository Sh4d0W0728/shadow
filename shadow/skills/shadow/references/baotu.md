# 包图网：会员浏览器接入

本模块用 Codex 可用的浏览器工具执行正常会员流程，配合 `assets.py` 管理本地文件；没有私有接口、Cookie 导出或账号密码存储。安装 skill 不等于安装浏览器控制能力。若当前会话缺少浏览器工具，明确缺项，继续处理本地素材，并请用户把正常下载文件放入项目下载目录。

## 搜索到归档

1. 进入 https://ibaotu.com/。查看当前页面的登录状态；已有会员会话就复用。需登录时打开登录入口，请用户扫码/验证码确认，等待页面显示成功再继续。登录完成前可并行整理本地素材。
2. 针对剪辑缺口搜索，不盲目批量下载。结合主体/动作/时间/景别等词，查看“视频 实拍”“MP4”等当前可见筛选。页面动态索引每次刷新，不硬编码按钮坐标或 DOM 序号。
3. 打开具体结果，读取标题、素材编号、尺寸、格式、时长、文件大小、作品页 URL 与当前会员入口。实际看预览判断是否合适；只把预览当筛选证据。
4. 先登记 candidate。作品页“立即下载”可能打开新标签页；重新列举标签并绑定下载页。选择账户正常可用的“个人VIP下载”或页面对应入口。用浏览器 download 事件取得完成后的本地路径，不把点击成功当文件成功。
5. 若网页要求验证码/付款/套餐升级/新协议，保留当前状态并按具体要求交给用户处理，继续独立工作。不能更改 URL 参数绕过权限，不能点广告中的升级按钮冒充下载。
6. 实际下载可能是 RAR/ZIP，不只 MP4。先列成员并验证安全路径、展开大小和压缩比，再用素材库支持的安全解包流程。文件夹里可能同时含原片、预览、水印图、DOC 授权附件；授权附件保留但不执行宏，预览标记 preview。
7. 对原片探测参数、计算 SHA-256、完整解码或抽样核验，再写来源和内容摘要。把源编号、来源页、下载日期、归档路径、原文件名、角色、页面权限说明和用途关联起来；不记录账户标识/令牌。
8. 导出素材清单与摘要，标明实际入选段落以及未解决的素材缺口。重新下载前按编号和哈希查重。

## 已实测页面路径（2026-10-09）

- 站内检索“山川 日出”得到“山川日出”结果。
- 作品 [航拍清晨大山日出](https://ibaotu.com/sucai/19673533.html)，编号 19673533，页面标示 MP4 / 1920×1080 / 00:11 / 86.28M。
- 作品页“立即下载”打开单独下载页，点击“个人VIP下载”取得真实 RAR 文件。由浏览器提供完成路径，没有下载预览地址冒充原片。
- 页面区分个人下载与公司使用授权。保留页面实际范围和附件信息；不能仅凭“VIP”把素材库授权字段设成“无限商用”。用途未明确时仅记录，不给法律结论。

以上是工作流例子，页面控件可能改变。后续依据当前页面操作，不假装官方公开 API 已接通。
