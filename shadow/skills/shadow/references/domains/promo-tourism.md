# 文旅目的地与文化推广片

面向潜在游客或关注地方文化的人，目标是建立一个具体目的地的吸引力和辨识度。基础配方 `product-promo`；地点组镜可参考旅行工作流。节奏参数可覆盖，不把“文旅”自动等同航拍、慢镜和宽银幕。

先确定目的地边界、季节、核心体验、文化主题与受众。素材优先是该地真实环境、人与活动、特色细节及可体验过程；图库必须核对实际地点。不可省略名称和地点归属；交通、开放时间、价格、非遗/历史称谓等只有真实来源才使用。不同地点素材不能被剪成同一景区的设施。

结构可从代表性感受或人物体验进入，按自然/文化/生活等少量主题组段，再回到一个清楚的体验承诺。先试每镜 2–6 秒；每组包含环境、行动和细节，留一两个现场声段落。通过行进方向、地貌或动作连接地点，转场用于空间/时间变化；文化表演的重要动作不要因卡点被切碎。

地点标题简洁准确，文化说明避免百科堆砌；字幕留开景物和表演主体。音乐应符合实际表达目的，保留市场、自然或活动声建立在场感；不能凭题材自动添加刻板民族音效。处理冷暖时保留当地真实季节与光线差异。

PR 交付包含地点—素材对应表、事实文案、音乐/现场声范围与源引用时间线；多画幅分别检查标志景物与标题。验收看观众能否辨认目的地、每个承诺能否找到真实体验、地名/季节/文化信息是否准确。与个人旅行 Vlog 的区别是目的地和游客价值主导；禁忌是跨地点冒充、只有风景而无体验，以及虚构开放/票务信息。
