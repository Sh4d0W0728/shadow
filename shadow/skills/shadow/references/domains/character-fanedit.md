# 影视人物与角色弧线混剪

面向已知或准备认识该角色的观众，目标是表达当前角色的处境、选择、关系或情绪变化。基础配方 `character-cinematic`。情绪范围可由用户指定，不能把“电影感”自动翻译成黑边、低饱和或某一帧率。

先锁定作品/版本、角色、素材范围、关键台词与参考主题。素材优先是有因果作用的行动、反应、冲突、代价与真实结果，视觉母题提供呼应。不可省略理解转变所需的关系和铺垫；台词说话人、原场景和人物身份不能被改归属。

结构可为状态—冲突/行动—代价—选择—结果，或用户给出的主题/情绪弧线。先试每镜 2–5 秒，关键表情和原声句子可更久；高潮不一定更快。动作/形状匹配连接有意义的场景，声音桥让台词解释相关画面，平行剪辑用于已建立的关系，而非随机切换角色。

保留有功能的原声、对白和音乐段落，字幕听校台词与角色名。不同作品/版本画面先匹配基本曝光和色彩解释，再按参考风格统一。复杂遮罩、分屏、速度曲线只在实际能力范围执行，不能靠效果掩盖人物逻辑缺口。

PR 交付含角色/作品身份、台词源位置、剧情节点、选镜用途、时间线/字幕与效果状态。验收回看关键场景上下文，检查角色转变是否有铺垫、台词原意与归属正确、主题能被描述。与卡点动作片的区别是人物变化主导，与观察纪录的区别是可以按明确主题重组虚构素材，但不能伪称原剧情事实；禁止误交另一角色/作品的工程。
