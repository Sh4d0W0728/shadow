# 观察式纪录与真实事件故事

面向想理解真实事件、人物处境或社会过程的观众，目标是让事实关系和变化可见。基础配方 `documentary-interview`，本页把现场行动放在采访之前。节奏范围可覆盖，不能为戏剧化改写事实。

先建立时间、地点、人物、事件范围与实际发生顺序；素材优先是现场行动、关键结果、可核对证据和同期声，采访用于解释而非取代缺失事件。不可省略理解因果所需的背景、时间间隔、重要不确定性与来源性质。不同事件的现场声/表情不能伪装成同一时刻。

结构可按“处境—行动—障碍—变化—结果/未解问题”组织真实素材。先试行动/环境镜头 3–8 秒，完整行为或证据需要更长；时间省略必须仍看得懂过程。平行剪辑可用于比较，但并不自动说明同时发生；声音桥与叠化要有时空理由。

字幕与地点/时间卡承担必要定位，解释文字区分事实、受访者说法与推测。现场声保留空间与行动，音乐少量支撑情绪；设计音效、复现画面或库存素材的性质应在记录/成片中适当明确。避免用持续煽情音乐替代事件本身的复杂性。

PR 交付包含事件时间线、源引用/证据表、已知缺口、可编辑剪辑结构和最终字幕；分离剪辑、降噪与复杂效果按实际能力完成。验收检查时空关系、因果是否有素材支持、角色归属、声音性质和限定信息。与访谈片的区别是实际行动主导，与影视混剪的区别是真实关系不能自由重构；不把好看的叙事顺序当成事实顺序。
