# 个人旅行与生活 Vlog

面向关注创作者体验、同行记忆或具体旅行过程的人，目标是保留“我/我们经历了什么、发现了什么”。基础配方 `travel-vlog`。路线、记录重点、人物与声音选择来自本次请求，不把地点宣传模板套成个人旅行。

先核对路线/地点、日期、参与者、重要经历和希望保留的对话。素材优先是实际行动、互动、具体细节、反应与现场环境；航拍/风景用于建立空间。不可省略理解行程与事件变化的背景、用户指定人物和重要互动，不把不同时地画面误标成同一段经历。

结构可为到达—探索—一个发现/互动—感受—收束，或按真实日常过程。每地先用环境、行动和细节成组，先试每镜 2–5 秒；具体体验需要时延长。重复路程可省略并说明地点变化，运动方向和构图帮助衔接，现场声桥带出空间；不要求每次都用甩镜。

标题只补必要地点/时间信息，字幕听校对话且不盖住风景主体。给有意义的现场声音、惊喜或停顿留空间，音乐在推进段托底，情绪段可降低或暂停；不把全部同期声替换成配乐。防抖、调色与放大按实际源质量使用，保持体验的真实质感。

PR 交付含行程与素材对应、人物/地点信息、原声保留范围、最终字幕和时间线；同内容横竖版独立构图。验收检查路线变化可懂、身份地点准确、具体经历被看见、声音与画面协调。与文旅推广的区别是个人经历主导，与当天活动快剪的区别是体验而非时限主导；避免只有无关漂亮景物或为了快切删掉重要互动。
