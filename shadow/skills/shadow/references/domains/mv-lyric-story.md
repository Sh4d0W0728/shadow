# 歌词叙事与抒情 MV

面向歌曲听众，目标是让画面与本次歌曲的含义、情绪和变化形成关系。基础配方 `mv-lyrics`。先锁定歌名/歌手、实际音频、歌词版本及使用范围；不要继承历史歌曲或任何旧项目参数。

素材优先是能承载主题的行动、表情、环境与反复意象；歌词是理解线索，字幕是否出现另按用户要求。不可省略当前媒体身份和用户要求的音频范围；歌词时间需要试听核对。没有完整音频时可以做明确范围的试剪，不能宣称完成全曲 MV。

按实际前奏/主歌/副歌/间奏/尾奏或真实乐句写情绪功能，再选少量意象连接段落。先试每镜 2–6 秒，情绪落点 4–8 秒是起点；歌词句末和音乐停顿可留呼吸。副歌需要能量时才加密重拍，叠化表达回忆/时间变化，匹配剪辑让意象呼应，不逐字找物件堆画面。

音乐是主声音；原声或设计声只有在表达需要且用户范围允许时加入。歌词字幕按语义断句并听校，不靠文稿字数伪造时间；排版留出主体与景物。风格调色先解决源画面一致性，再按当前参考片处理，不默认电影黑边或固定帧率。

PR 交付含乐段/歌词时间表、意象与选镜用途、源音频、最终 SRT（如需要）、时间线/成片；可编辑歌词文字与图像文字层区别声明。验收核对歌曲/歌词/工程/导出身份、音频完整、情绪段落变化和关键语义。与卡点 MV 的区别是歌词情绪主导；禁忌是漂亮镜头和重拍掩盖歌曲含义，或把别的歌曲工程当作完成。
