# 会议演讲、发布会与报告记录

面向要获取演讲内容的观众、参会者或资料留存者，目标是保存可理解、可追溯的报告。基础配方 `talking-head`。先判断用户要完整记录、压缩整理还是精彩摘要；不能因为同样来自活动就自动用快剪。

素材优先是连续可靠的讲话音轨、讲者画面、与实际页次对应的投影/PPT、重要提问与回答。不可省略讲话身份、主题、关键论证和限定条件；完整记录还须保持要求范围。声音断点、幻灯片版本和页次缺口先列出，不能用相似页或不同句子拼补成伪完整。

结构沿演讲实际逻辑：问题/背景—方法或论证—证据/示例—结论—问答；长片可按章节标记。切镜以完整短语和幻灯片变化为依据，先试讲者/投影 5–15 秒只是起点；复杂图表应更长。插入相关画面帮助理解，少用音乐节拍和装饰转场；跨音画编辑需要实际保留连续讲话。

字幕听校术语、人名、数值、单位和否定词，标题写讲者、机构与报告主题。屏幕内容先确保在目标尺寸可读；多机位与录屏声画同步。原则上原声主导，是否配乐由用途决定；不要给完整学术报告默认铺持续音乐。

PR 交付包含音轨/机位同步记录、源范围、章节、字幕与可追溯时间线；SRT 保持最终序列时间，必要的文字重建在原生工程进行。验收听完整意思、检查全部页次和关键数值、头中尾同步，以及约定范围未漏。与网络课程的区别是忠实报告优先，与活动回顾的区别是信息而非现场气氛优先。
