# 卡点 MV 与动作节奏混剪

面向希望获得音乐/动作能量的观众，目标是让乐段、重要节拍与动作峰值互相强化。基础配方 `music-montage`。拍点只是切点候选，试听和动作可读性优先；不规定每拍都切。

先确认配乐版本与范围、动作主体、可用镜头质量和峰值。素材优先是动作起止清楚、方向可接、景别有变化的片段；无清楚动作的“酷炫”镜头后置。不可省略用户指定的重要动作和音乐段落，不能用剪点/速度效果伪装源素材中不存在的动作结果。

按音乐真实段落建立开场、递进、峰值和释放。先试每 2–4 拍一镜，高潮短暂加密；同动作换角度时在动作中段寻找连贯接点。强拍用于视觉重点，少量切分带来变化。运动转场需要方向/构图关系，速度渐变只在实际工具支持且验证后使用，保留原片和目标倍率计划。

音乐主导，动作原声与音效选择少量明确点，不每个剪点加 whoosh。字幕/标题保持克制，只承担身份或必要信息；用户要歌词字幕时核对当前歌词，而不改变主节奏策略。剧烈闪切和大幅光效若妨碍观看就减少，不能把效果数量当成能量。

PR 交付含拍点/动作峰值表、源选段、时间线、已执行与待精修效果清单；高级速度曲线需 PR 原生处理，不假称基础时间线自动实现。验收试听关键拍、检查动作完整和方向、递进后有释放、无意闪帧/重复帧。与歌词 MV 的区别是节奏和动作主导，与影视人物片的区别是人物弧线不是必要主线。
