# 活动完整回顾与年度纪念片

面向参与者、未到场者或组织内部留存，目标是回顾真实活动的主要进程、人物和结果。基础配方 `event-recap`。完整回顾指约定范围覆盖齐全；用户要求逐场全程实录时要按记录需求保留时长，而不是套精彩快剪。

先建立活动流程与必留清单，核对日期、名称、人员和各阶段素材。优先选建立环境、关键行动、讲话核心意思、参与者反应与结束结果。不可省略用户指定环节和关键声音；多机位先按真实时刻对应，不能拿其他时刻的表情冒充同期反应。

结构按真实流程或经约定的主题组织，每段要有不同作用：到场/准备、开展、高潮、结果/告别。先试每镜 2–5 秒，讲话和仪式按意思/动作完整性延长；不同阶段允许不同密度。硬切推进事实，环境声桥连接场景，叠化说明时间变化，章节信息帮助长片定位。

标题准确区分环节和人物，讲话字幕听校人名、机构和数字。音乐围绕重要原声起伏，不持续盖住演讲、誓词或结果宣布。画面先匹配多机位曝光/白平衡；包装围绕真实活动识别，避免每阶段都是同一套炫技转场。

PR 交付含覆盖清单、源时刻、讲话范围、可编辑时间线和成片；完整实录与精彩摘要需要时分版标明。验收逐项勾对必留内容、人物、时序、声音与结尾，并查看每个阶段都有实际素材。与当天快剪的区别是流程覆盖和留存价值优先，与会议演讲的区别是活动全景优先；不把剪辑漂亮等同覆盖完整。
