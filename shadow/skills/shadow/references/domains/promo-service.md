# 服务体验与流程推广片

面向准备选择某项服务的人，目标是说明服务如何解决问题、用户会经历什么、结果和边界是什么；培训/课程招生广告也属于选择服务的推广，不是授课内容。基础配方 `product-promo`。流程真实性与受众理解优先，镜头范围仅为可覆盖起点。

先确认服务对象、使用场景、实际流程、可证明结果与联系路径。素材优先是用户需求、服务人员动作、关键交互、过程节点和实际交付；豪华空间不能代替服务证据。不可省略谁适用、必要条件、重要步骤和结果限制。用户案例、等待时间、效果承诺及评价归属需要输入依据。

结构可为用户问题—进入服务—2–4 个关键动作—真实结果/感受—下一步。先试每镜 2–5 秒，交互与反馈按能看懂留足时间。动作接剪维持流程，跳过重复步骤时用状态/时间提示；叠化只表示真实等待或阶段变化，不让前后拼接伪装立刻见效。

标题说明用户获得什么和需要什么，而非逐项罗列设备；流程标注简短，角色身份明确。采访或真实反馈需要完整原意；旁白与现场声先保持可听性，音乐支撑体验。涉及示范与实际案例的差别，在画面/记录中说明，不能把演示当作实证。

PR 交付含流程/事实对照、镜头用途、审定文案、字幕及时间线；原生图形和复杂跟踪按支持能力精修。验收要求观众能说清服务过程与限制、声音和动作相符、CTA 可执行。与产品功能片的区别是人与服务过程主导，与教程的区别是选择价值主导；避免省掉影响结果的步骤、编造客户反馈和一串无证据的效果词。
