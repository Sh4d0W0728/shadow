# 社交商品推广与转化短片

面向可能选择商品/服务的社交平台受众，目标是用短时间说清一个真实利益点、证据与下一步。基础配方 `product-promo`；首屏与目标尺寸按社交工作流检查。所有节奏起点服从当前投放要求。

先锁定具体商品/型号、受众问题、主卖点、可证明镜头、实际价格/优惠与链接输入。素材优先是结果/使用问题、清楚产品、真实操作和证据，不先做空泛品牌氛围。不可省略重要使用条件、限制、型号归属和 CTA 的真实目标；没有优惠/价格来源就不增加。

结构可为一个问题或实际结果—产品解决方式—简短证据—必要条件—明确下一步。首 1–3 秒是试剪起点，每镜约 1–3 秒，细节和参数要看得清；只保留一个主卖点比不断堆新承诺更容易理解。重拍用于揭示，转场用于展示阶段；前后对比必须使用公平条件。

标题强调利益而非无依据的绝对化词，字幕不挡关键操作和商品。按实际平台 UI 预览价格、按钮及文案区域；音乐让位说明，音效只强调实际动作。CTA 可是查看详情、联系或购买，但不能虚构按钮/链接行为，不能把文本出现称为已完成发布。

PR 交付含事实/优惠来源、审定短文案、各比例版本、SRT 与时间线/成片；投放/外部发布另按真实授权执行。验收看利益与证据匹配、条件齐全、型号价格正确、CTA 可执行和平台可读。与完整产品片的区别是单点短转化主导，与社交信息片的区别是选择行动主导；禁止假见证、误导对比和虚构促销。
