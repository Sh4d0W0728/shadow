# 活动当天快剪 / 现场即时回传

面向现场观众、主办方或活动当日的线上受众，目标是在明确截止前交付当下可发布的精彩摘要。基础配方 `event-recap`。速度来自先设优先级和收紧交付范围，不能靠跳过身份与关键内容检查。

开剪前锁定截止时间、审片窗口、输出渠道、必留人物/环节、可用配乐与收到素材的时间。优先入库已完成传输、声音可用、关键时刻明确的片段；先建立备选镜头，不等所有素材齐全。不可省略活动名称、当天身份、约定核心时刻和主办方要求信息；尚未发生的环节不能用旧素材冒充当天。

结构先用环境/身份建立现场，再穿插重要行动、参与者反应和一个峰值，留简洁收束。先试 30–90 秒或用户范围，每镜约 1–4 秒；讲话要完整到一个意思。切镜追随行动和现场节奏，少量有动机叠化即可；复杂包装若会挤掉审片/导出时间，缩减为清楚标题和硬切。

标题优先活动名、人名与必要日期，避免临时长文案。音乐稳定托底，给关键讲话/欢呼留空间；字幕只做听校过的实际句子。采用少量已确定字体、颜色和图层样式，收到后续素材可替换备选，不临时重建全片风格。

PR 交付含即时成片、已选源段/清单、当前时间线及“尚未收到/未覆盖”记录；可另存后续回顾版本。验收先查核心清单、真实日期/人物、声音、头尾、参数和截止前可用文件。与完整回顾的区别是截止和现场范围优先，与会议演讲的区别是当日摘要优先；禁止将未收到素材报告为已覆盖，也不默认把第一次即时版当成完整活动记录。
