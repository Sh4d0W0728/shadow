# 屏幕操作与软件教程

面向要在自己的软件/设备中复现操作的人，目标是看清入口、动作、参数与结果。基础配方 `tutorial`。操作可复现优先于片长，缩放和停留只作为试剪起点。

先锁定软件版本/语言、目标任务、前提状态、录屏与讲解音轨；差异版本会改变按钮位置。素材优先是完整正确的操作链、关键参数输入和结果验证；鼠标移动的装饰过程可省略。不可省略路径、影响结果的选项、等待条件、保存/导出位置及必要失败提示，不能让剪接看似一步完成实际多步任务。

结构为目标/初始状态—按顺序操作—关键设置—结果验证—必要排错。等待和重复步骤可压缩，但用状态或时间说明变化。每次操作先让目标控件可辨，再给动作和反馈；重要区域可先试放大约 110–140%，前提是清晰度和上下文仍成立。硬切用于等待省略，复杂转场会干扰定位。

标注一个动词＋对象，箭头/框选不得遮住控件与参数；字幕优先放空白区。讲解与点击、输入、结果变化对应，必要时留 1–3 秒观察起点再按实际内容延长。原声清楚优先，少量提示音用于区分状态；不默认增加点击音到每次鼠标动作。

PR 交付含源录屏、步骤/参数表、最终时轴 SRT、工程与成片；追踪标注和复杂图形仅在实际工具支持时执行。验收在目标尺寸读取全部参数，按片子从头复现并找到结果，核对版本、路径与字幕同步。与概念微课的区别是操作链主导，与产品推广的区别是复现而非选购主导；禁止裁掉错误信息或关键保存位置。
