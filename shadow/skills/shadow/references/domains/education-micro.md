# 微课与单知识点教学

面向想快速掌握一个概念、方法或常见误区的学员，目标是完成一个可检验的小学习结果。基础配方 `tutorial`。微课长度没有统一强制值，用户要求与知识复杂度优先；短不等于只保留结论。

先把目标写成“看完能解释/完成什么”，限定一个主知识点和所需前提。素材优先是核心解释、一个清楚示例/对照和实际结果；背景铺陈后置。不可省略理解结论所需的条件、关键定义和验证依据，尤其不能把有范围限制的方法讲成万能技巧。

结构可为一个问题—最少前提—核心方法/解释—一个例子—验证/回顾。先试 1–5 分钟或用户范围，镜头由语义与示例决定；复杂图解停得足够看清。用一次清楚的对比或放大解释差异，转场只表示学习阶段，不为每句话添加动效。

标题沿“问题/概念/方法/结果”保持层级，屏幕一次只引入少量信息。字幕与示例中的数值、符号保持一致，重要条件可重复强调；图像文字若由脚本生成，保留原文和时间点。原声讲解优先，音效仅用作少量学习反馈，音乐避免与解释争夺注意力。

PR 交付含单节成片、源段、最终时轴字幕、简短教学目标/验收题与工程交接。验收让一名目标水平观众能够说出核心概念或复现步骤，检查例子、限定语和可读性。与系统课程的区别是一项学习结果独立成立，与社交信息短片的区别是理解/掌握主导；避免快切使推理断裂或将重点词堆屏当作教学完成。
