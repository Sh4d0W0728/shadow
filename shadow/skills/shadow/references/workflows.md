# 12 套可复用剪辑工作流

读取与任务匹配的一节即可；共同原则在入口技能中，技巧的条件、起点和实现状态见 [techniques.md](techniques.md)。配方是可修改的起点。用户的实际素材、参考片、时间点、故事含义、软件版本和输出要求覆盖这里的建议。

## 快速选择

| 配方 ID | 主导输入 / 目标 | 优先决定什么 | 常见可选扩展 |
|---|---|---|---|
| mv-lyrics | 完整歌曲＋歌词，以歌词情绪叙事 | 歌曲/歌词对应关系、意象、段落情绪 | 副歌重拍、视觉母题、少量歌词字幕 |
| music-montage | 音乐＋动作/精彩镜头，以节奏为主 | 乐段和强拍、动作峰值 | 速度渐变、运动转场 |
| character-cinematic | 角色或影视素材，表达人物弧线 | 角色身份、前后因果和情绪转变 | 原声桥、重复意象、长镜停留 |
| talking-head | 口播/讲解，以信息可懂为主 | 观点、赘语、可听性 | B-roll、温和 Punch-in |
| tutorial | 操作或教学，观众要复现 | 必要步骤、参数、结果验证 | 放大细节、步骤指示 |
| product-promo | 产品/品牌/服务，说明价值 | 可证明的利益点和产品事实 | 微距、对比、行动引导 |
| documentary-interview | 采访/纪实，以真实观点和事件为主 | 原意、证据、时空关系 | J/L cut、环境底、现场 B-roll |
| travel-vlog | 旅行/日常，以体验和空间变化为主 | 地点、过程、感受、细节 | 环境声、章节、音乐段落 |
| event-recap | 活动精彩回顾，以覆盖关键环节为主 | 活动身份、必留人员和时刻 | 反应镜头、现场声、高潮段落 |
| social-short | 短内容，以一条可立即理解的信息为主 | 首屏、单一主题、字幕可读 | 循环结尾、音效标点 |
| long-to-short | 从现有长片拆出独立短片 | 原上下文、独立成立、保留限定语 | 新开头、竖版构图、短结尾 |
| general-story | 类型不明确但有成组素材 | 清楚主线、必要信息和节奏 | 选择一个最有用的专用工作流 |

“电影感”可以表示叙事、构图、光线、声音和节奏；不要自动改成某个帧率、宽银幕黑边、低饱和或某类转场。没有强主导类型时采用 general-story，再用素材验证是否需要专用配方。

## mv-lyrics — 歌词驱动 MV

**最少输入：**实际歌名/歌手或可核验音频身份、可用完整音频、歌词（如任务依赖其含义）、视觉素材与成片范围。无完整音频时可制作标明范围的局部试剪，不能宣称完整 MV 已完成。

先试听并核对歌词时间，将歌曲标为前奏、主歌、预副歌、副歌、间奏、尾奏等实际存在的段落；名称不适用时按真实乐句分段。每段写一句情绪功能，再从歌词提炼 1–3 个反复出现的意象；画面可以表现含义和反差，避免逐字寻找物件。先以 S01、R01、R05、R08、T05 搭主线。副歌需要加速时才加入 R02/R04；情绪落点可以暂缓切镜。

第一次试剪选一个具有前后变化的 15–30 秒片段，不只挑全片最容易的一段；预览确认歌曲、歌手、歌词、画面意图和文字身份相符后扩到全片。歌词字幕是独立选择，不应仅因存在 LRC 就默认烧录。字幕需要可编辑时在 Premiere 做字幕轨，不把 XML 当成字幕效果实现。

**验收重点：**请求的歌与音频/歌词/工程/导出名称一致；音频完整性与指定范围；歌词语义没有误读；情绪段落有区别；旋律停顿和歌词句尾有呼吸。v2 可执行基础剪辑、转场、标题字幕与预览；调色、复杂音效和速度曲线需在 Premiere 实际精修。

## music-montage — 卡点 / 动作蒙太奇

先听出音乐结构，记录明确重拍和动作峰值；自动检测只能提供候选，不能替代试听。用 R01、R02、R04、C02、C08 对齐重要动作，不需要每拍切。先试每 2–4 拍一镜，高潮可以短暂变密；在段落结尾留一个 R05 释放镜头。动作峰值在源镜头中不可见时更换镜头，不用特效冒充动作。

R07 速度渐变与 V07 运动转场是可选精修。需要 R07 时记录开始、峰值、结束以及预期倍率，留给 Premiere 原生 Time Remapping；不要把平均帧率转换当成变速。相似方向、构图或动作节奏可直接硬切衔接。

**验收重点：**关键拍点试听一致；动作起止可读；高潮有递进；未出现随机短镜、过度闪切或无意义甩镜。对节奏的观感判断属于预览结果，不能只靠时间码表证明。

## character-cinematic — 人物 / 影视混剪

先锁定当前角色、作品版本和素材范围，建立“状态—冲突/行动—代价—选择/结果”的真实主线；结构不适合时按用户的情绪或主题重排。为每个重要原声保留上下文和说话人。使用 S01、S06、R05、R08、C03 组织镜头，穿插 A06 原声桥或 S07 平行剪辑时明确其关系。

不要仅按“好看镜头＋悲伤音乐”排列。关键转变前可让动作、表情或原声承担铺垫，转变后用同一母题的新语境体现变化。选择片中确有的线索，不能虚构角色关系或把不同角色的台词重新归属。

**验收重点：**角色和作品正确；台词没有改意；引用场景与表达关系成立；主线/情绪可描述；素材来源和可用范围有记录。调色和运动效果不会替代人物逻辑。

## talking-head — 口播 / 讲解

先用 A01、S04 组出可独立听懂的观点，再处理画面。删去重复内容、明显空转、误录和无作用的停顿；保留必要限定、感情和自然呼吸。C07 跳切在此可以成立，若跳切干扰才用 C06/V10 相关 B-roll 或 V08 温和放大。

使用 T01/T02 做可读字幕时须听校人名、数值、否定词。A05 压低音乐以保证对白，不能把环境噪声当作音乐掩盖掉。对话原声应先得到合适处理与试听；本插件基础 XML 的背景音乐能力不等于对话分离、降噪和自动 Ducking。

**验收重点：**不用看画面也能理解意思；口型和原声同步；删句未改变立场；字幕正确；跳切与构图变化有信息功能。

## tutorial — 教程 / 操作演示

采用 S01、S09、S10、T04、V10：目标/前提—步骤—常见失败点—验证结果。先区分哪些动作可以省略，哪些必须完整呈现（参数输入、材料剂量、关键等待条件、结果检查）。界面操作前或同时给观众看清按钮、路径和数值；等待与重复操作可跳过，但标明时间或状态变化。

把画面和说明按操作顺序对齐。R09 并列对比或 V04 放大仅用于帮助辨认差异；如果会遮盖参数，优先独立清晰镜头。不要套快节奏使步骤无法复现。成片需要超过短片配方长度时，按步骤需要增加。

**验收重点：**观众能够复现关键过程；前提和参数可读；等待条件没有变成错误动作；最终结果实际展示；字幕不遮挡操作区域。

## product-promo — 产品 / 服务介绍

先确认真实产品、受众、一个主价值与能够证明它的镜头/数据。用 S02、S05、C05、V10、T03 从问题或结果进入，再展示功能证据，最后 T06 给实际存在的下一步。用户要纯视觉展示时以材质、形状、使用场景和动作组织，不自行增加价格、性能或广告词。

每个卖点对应一个有效镜头。V01 先修一致性，再 V02 统一风格；可选 C03 图形匹配和 R02 重拍用于一次明确揭示。用 R09 前后对比时保持比较条件，不能用不同光线或处理伪造产品功效。

**验收重点：**产品型号/名称无误；每条事实有输入依据；画面清楚展示产品；文本可读；CTA 指向真实可执行目标；没有未经确认的价格、链接和承诺。

## documentary-interview — 纪录 / 访谈

用 S04、A01 先建立原意和证据链，再放 C06/V10 真实相关 B-roll。剪句不能改掉限定条件、先后关系和人物立场。记下说话人、原始时间段和上下文；事实剪辑以真实性为先，允许停顿与复杂观点存在。

A02 J cut 让下一场原声先进入，A03 L cut 让当前话语延续到相关画面；A04 同场环境底减少突变。音频与视频须在 Premiere 分离编辑并试听，当前基础时间线不自动生成 J/L cut。使用跨场声桥、非同期反应或库存镜头时，避免造成发生在同一时空的误解。

**验收重点：**原意与证据成立；说话人归属准确；B-roll 相关；真实时空关系没有被剪接伪造；原声接缝自然；字幕听校正确。

## travel-vlog — 旅行 / 日常记录

采用 C05、C08、S09、R01、A06 建立空间和体验：到达—探索—一个具体发现/互动—收束。不必每次都完整走这四段；先尊重用户旅行路线、时序与记录重点。每地点以环境、人物/行动、细节组成一小组，而非仅用连续航拍或风景。

重要现场声和对话给独立空间；音乐段落负责推进时，保留一两个安静或低音乐镜头呈现感受。重复路程用 S09 压缩，跨地点可用 S10 简洁地点信息。叙事需要人物反应时加入 S06。

**验收重点：**地点/日期不误标；空间和路线变化易理解；体验有具体细节；现场声与音乐协调；重要人物和行动没有被素材漂亮程度挤掉。

## event-recap — 活动 / 婚礼 / 会议回顾

先列用户指定的必留人物、环节、讲话、仪式和真实高潮。用 S01、S06、C05、R04、R05 从建立环境到重要行动、参与者反应和收束；按活动事实排序，只有用户要求主题式结构时重排。完整记录和精彩回顾是不同目标，前者不能用快剪配方省掉指定环节。

关键讲话、誓词或现场欢呼优先保留可懂原声，音乐围绕它调整。多机位按动作和声音同步，不能用不同时刻的镜头制造假反应。人名、日期、机构名称和活动标题用实际来源核验。

**验收重点：**必留清单全覆盖；事件、人员、日期正确；重要声音完整；高潮明确；导出范围和用户要的记录/回顾类型一致。

## social-short — 短社交视频

只选一个主要信息或完整小故事，使用 S02、C01、S09、T01、T03。先试首 1–3 秒让观众知道主题或结果，随后每个镜头推进它；不机械套“每秒都切”。视觉细节需要读的时候就留够时间。内容依赖声音时增加经听校的字幕，按实际平台 UI 与目标尺寸看遮挡。

用户给目标比例时遵从；未指定时用现有序列或询问真实用途，不因“短视频”自动认为全部要 9:16。A07 音效与 D03 循环仅在内容适合时使用。CTA 需要用户确有推广/引导目的。

**验收重点：**首屏含义清楚；主信息单一；无声观看仍可懂必要内容；文字未被遮挡；目标比例、时长和音频范围实际满足。

## long-to-short — 长片拆条 / 再利用

先读/听原段前后上下文，选 D04 可独立成立的完整观点或事件。用 S04、S02、S09 重构最少必要背景，保留证据、结果和限定词。不能仅依据播放热词抓一句刺激台词。目标长度不够容纳完整意思时选择别的段落，或明确交付为预告/摘录。

用 D02/V04 另做构图、T01/T02 另做字幕；保留原长片引用位置方便追溯。新标题和首屏应与摘出的段落一致。横竖版不能靠中心裁切一键认定完成；每镜主体、手势、产品和 UI 需再检查。

**验收重点：**片段独立可懂且不改原意；原片引用存在；新标题准确；构图适合目标尺寸；字幕/原声同步；没有裁掉关键内容。

## general-story — 通用叙事 / 素材不足时

先用 S01 给素材标注“建立、行动、细节、反应、结果”的功能，再用 C01、C05、R05、V10 组清楚的最小主线。没有动作或结果素材时把缺口说清楚，可交付现有范围的试剪或选镜计划，不生成并不存在的证据。随后按实际素材转向上面的某个配方，或保留一个简单结构。

**验收重点：**镜头顺序能被解释；没有无来源叙事；必要信息齐全；节奏与内容相符；用户目标在成片中真实出现。

## 可编辑交接

所有工作流均可以先给镜头/声音/文字决策表。基础脚本输出的可导入 XML 只证明建立了受支持的时间线结构。未由脚本实际实现的调色、复杂转场、J/L cut、速度曲线、分屏、防抖和自动选好镜头，放在精修清单中；在 Premiere 实际执行、试听/观看后才升级完成状态。具体见 [premiere.md](premiere.md)。
