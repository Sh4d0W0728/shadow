# shadow 兼容时间线 v1

用 JSON 保存真正选定的素材和切点。它既是脚本输入，也是后续修改的依据。本页仅描述旧 v1 输入；新任务使用 [v2 格式](timeline-v2.md) 以启用转场、静态图、标题和字幕。

```json
{
  "schema_version": 1,
  "project": {
    "name": "我的剪辑",
    "width": 1920,
    "height": 1080,
    "fps": "25",
    "sample_rate": 48000
  },
  "identity": {"title": "用户指定作品", "music_title": "用户指定歌曲"},
  "clips": [
    {"source": "素材/镜头一.mp4", "in": 1.2, "out": 4.2, "label": "开场细节", "audio": true},
    {"source": "素材/镜头二.mp4", "in": 0, "out": 2.0, "label": "动作接续", "audio": false}
  ],
  "music": {"source": "素材/音乐.wav", "in": 0, "gain_db": -12}
}
```

- `source` 可以是绝对路径，或相对于这份 JSON 所在目录的路径。中文和空格可以使用；本地文件需实际存在且能解码。
- `in` / `out` 是源素材的秒数，`out` 为不包含的终点。必须满足 `0 <= in < out <= 素材时长`。
- `clips` 按排列顺序紧接；不表示独立轨道、间隙、重叠、变速或转场。源音频按 `audio` 选择，默认 true；缺少源音频的预览段会补静音。
- `fps` 采用整数/分数，例如 `25`、`24000/1001`、`30000/1001`。用分数避免把 29.97 误当精确十进制帧率。脚本报告帧量化后的实际序列长度。
- `music` 为可选的独立背景音乐；`in` 默认 0，`gain_db` 默认 0。音乐短于序列时会明确警告，剩余部分保留静音；不自动循环。用户要求全片有音乐时需由执行者补齐正确素材或调整时间线。
- `sample_rate` 可选，默认 48000。源帧率可以不同，脚本记录源帧率并输出明确的序列帧率。
- `identity` / `title` 只是项目元数据，不会自动生成片头文字，也不会证明路径里的歌曲是所需歌曲。执行者仍需对照用户要求核验真实身份。
- 宽高必须满足编码要求；没有指定时上面的 1920×1080/25 只是示例，不能覆盖用户规格。

不要在此输入任意 FFmpeg 命令或过滤器字符串。高级效果采用当前已验证的编辑软件/工具；如需扩展脚本，先单独验证行为。
